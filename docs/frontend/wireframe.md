# 지도 + Bottom Sheet 와이어프레임

## 모바일 1화면 구조

```text
+------------------------------------------------+
| [검색] [평형필터] [예산필터] [공사범위필터]       |
|------------------------------------------------|
|                                                |
|                 지도(Map)                       |
|        (줌아웃: 클러스터, 줌인: 단지 핀)         |
|                                                |
|   o 12   o 8       ● 단지A     ● 단지B         |
|                                                |
|------------------------------------------------|
|  Bottom Sheet (핀 클릭 시 올라옴)               |
|  단지명 / 주소                                  |
|  [59] [74] [84] [101]   <- 타입 칩              |
|------------------------------------------------|
|  포트폴리오 카드 스크롤                         |
|  [전/후 이미지] 제목                             |
|  스타일 | 공사범위 | 예산대 | 기간 | 업체        |
|  [저장] [문의]                                  |
+------------------------------------------------+
```

## 상호작용 플로우
1. 지도 이동/확대 시 `GET /map/pins`
2. 핀 클릭 시 `GET /complexes/{complex_id}`
3. 타입 칩 선택 시 `GET /complexes/{complex_id}/portfolios?unit_type_id=...`
4. 필터 변경 시 같은 포트폴리오 API 재호출
5. 저장 버튼: `POST /favorites`
6. 문의 버튼: `POST /quote-requests`

## 성능 포인트
- `map/pins` 호출은 300ms 디바운스
- 줌 전환 경계: `11 -> 12`에서 클러스터/핀 모드 변경
- 포트폴리오는 `limit/offset` 무한스크롤
